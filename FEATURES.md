## FULLY_FUNCTIONAL

| Feature                                    | What it does                                                                                                                                                                                                                                                                                                                                         | Evidence                                                                                                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Surface discovery                          | Walks a repo and models every Go version declaration: go.mod `go` directives (all modules, with module paths), go.work, `toolchain` directives, flake.nix nixpkgs pins (attribute + builder forms), CI `go-version:` pins. Skips vendor/node_modules/.git/result; skips flake.lock. Expression/range CI pins are skipped as non-comparable           | `pkg/surface/discover.go`, `pkg/surface/surface.go` (the `Surface` type)                                                                               |
| Policy analysis                            | Six rules: patch-form go.mod directive, patch-form go.work directive, Nix pin below effective floor, CI pin below effective floor, CI patch-form pin, stale `toolchain` directive. The effective floor is the module floor raised by a newer `toolchain` minor. Unparseable go.mod files surface as a discovery finding instead of aborting the walk | `pkg/surface/rules.go` (`Analyze`), `pkg/surface/surface.go` (`Rule` constants)                                                                        |
| Mechanical auto-fix                        | Directive form normalization via `go mod edit` / `go work edit`, never text rewriting; a fix counts as applied only when re-parsing the file shows the target directive                                                                                                                                                                              | `pkg/fix/fix.go` (`Apply`, `applyOne`)                                                                                                                 |
| Tidy-stability + dep-forced classification | go.mod fixes must survive `go mod tidy`; when tidy re-raises the directive, the fix is classified dep-forced and the poisoning dependencies are resolved via `go list -m` and named as supply-side re-tag targets                                                                                                                                    | `pkg/fix/fix.go` (`ensureTidyStable`, `resolvePoisoners`); dogfooded: this repo's fix reports go-finding, go-finding/toolsdk, linter-autoconfigure-sdk |
| go.work workspace-floor targeting          | A go.work below the workspace floor is rewritten to the floor (not the stripped directive), so the workspace can still resolve its own modules                                                                                                                                                                                                       | `pkg/surface/rules.go` (`formIssues`), regression `pkg/surface/discover_test.go` (`TestAnalyze_GoWorkTargetRespectsWorkspaceFloor`)                    |
| Suggestion engine                          | Alignment issues (pin vs floor) carry actionable suggestions; downgrades are never auto-applied — which side moves is a maintainer decision                                                                                                                                                                                                          | `pkg/surface/rules.go` (`nixPinIssues`, `ciPinIssues`)                                                                                                 |
| who-forces dependency-floor matrix         | For every go.mod: the highest `go` floor its dependencies declare, which dependencies carry it, and whether tidy would re-raise the directive — the poisoner matrix behind dep-forced fixes                                                                                                                                                          | `pkg/fix/who.go` (`AnalyzeFloors`); `go-version-auto-configure who-forces [root ...]`                                                                  |
| Parallel multi-repo sweeps                 | `check`/`fix`/`who-forces` accept multiple roots analyzed in a bounded worker pool, reported sorted by root; `fix` skips clean repos entirely (no go invocations) — sweeps scale with drifted repos, not repo count                                                                                                                                  | `cmd/go-version-auto-configure/main.go` (`analyzeAll`, `applyAll`)                                                                                     |
| JSON output                                | `--json` on check/fix/who-forces emits a stable camelCase machine contract (per-repo findings, counts, applied/held-back/dep-forced/failures, floor matrix) via `encoding/json/v2`                                                                                                                                                                   | `cmd/go-version-auto-configure/json.go`, `pkg/fix/who.go` (`ModuleFloors` tags)                                                                        |
| BuildFlow provider                         | Self-registering `toolsdk.Spec` via linter-autoconfigure-sdk's `ProviderFromSpec`; Detect + Repair; triggers on go/go.mod/go.work; honors BuildFlow dry-run context; HealthCheck verifies the go binary (context-aware)                                                                                                                              | `pkg/provider/provider.go` (`mustProvider`)                                                                                                            |
| CLI                                        | `check [--json] [root ...]` (exit 1 on drift), `fix [--dry-run] [--json] [root ...]`, `who-forces [--json] [root ...]`, `version`                                                                                                                                                                                                                    | `cmd/go-version-auto-configure/main.go` (`run`)                                                                                                        |
| Test suite                                 | surface (parse/discover/analyze incl. toolchain + workspace-floor regressions), fix (edit verification, dep-forced naming, subdirectory modules, floor matrix), provider (registration, detect/repair/dry-run), CLI end-to-end incl. JSON contracts; all parallel, race-clean                                                                        | `GOEXPERIMENT=jsonv2 go test -race ./...` — 5 packages ok                                                                                              |
