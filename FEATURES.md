## FULLY_FUNCTIONAL

| Feature                                    | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Evidence                                                                                                                                     |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Surface discovery                          | Walks a repo and models every Go version declaration: go.mod `go` directives (all modules, with module paths), go.work, `toolchain` directives, flake.nix nixpkgs pins (attribute + builder forms), CI `go-version:` pins. Skips vendor/node_modules/.git/result; skips flake.lock. Expression/range CI pins are skipped as non-comparable                                                                                                                                             | `pkg/surface/discover.go`, `pkg/surface/surface.go` (the `Surface` type)                                                                     |
| Policy analysis                            | Eleven rules: patch-form go.mod directive, patch-form go.work directive, go.work below the workspace module floor, Nix pin below effective floor, CI pin below effective floor, CI patch-form pin, stale `toolchain` directive, non-version `toolchain` name, unparseable go.mod/go.work (discovery findings instead of aborts or silent drops), and minor above the fleet expectation (`--expect-minor`). The effective floor is the module floor raised by a newer `toolchain` minor | `pkg/surface/rules.go` (`Analyze`), `pkg/surface/surface.go` (`Rule` constants)                                                              |
| Mechanical auto-fix                        | Directive form normalization via `go mod edit` / `go work edit`, never text rewriting; a fix counts as applied only when re-parsing the file shows the target directive                                                                                                                                                                                                                                                                                                                | `pkg/fix/fix.go` (`Apply`, `applyOne`)                                                                                                       |
| Tidy-stability + dep-forced classification | go.mod fixes must survive `go mod tidy`; when tidy re-raises the directive, the fix is classified dep-forced and the poisoning dependencies are resolved via `go list -m` (with a `go list -e` fallback for untidy trees) and named as supply-side re-tag targets                                                                                                                                                                                                                      | `pkg/fix/fix.go` (`ensureTidyStable`, `resolvePoisoners`); post-campaign dogfood: this repo's graph is clean (`fix` applied 0, dep-forced 0) |
| go.work workspace-floor targeting          | A go.work below the workspace floor is rewritten to the floor (not the stripped directive), so the workspace can still resolve its own modules                                                                                                                                                                                                                                                                                                                                         | `pkg/surface/rules.go` (`formIssues`), regression `pkg/surface/discover_test.go` (`TestAnalyze_GoWorkTargetRespectsWorkspaceFloor`)          |
| Suggestion engine                          | Alignment issues (pin vs floor) carry actionable suggestions; downgrades are never auto-applied — which side moves is a maintainer decision                                                                                                                                                                                                                                                                                                                                            | `pkg/surface/rules.go` (`nixPinIssues`, `ciPinIssues`)                                                                                       |
| who-forces dependency-floor matrix         | For every go.mod: the highest `go` floor its dependencies declare, which dependencies carry it, and whether tidy would re-raise the directive — the poisoner matrix behind dep-forced fixes. Every forcing dependency is carried with its own floor (`poisonerFloors`); `--allow-partial` downgrades per-module `go list` failures from exit 2 to exit 1; go.work rows are marked and skipped with a note                                                                              | `pkg/fix/who.go` (`AnalyzeFloors`); `go-version-auto-configure who-forces [root ...]`                                                        |
| Parallel multi-repo sweeps                 | `check`/`fix`/`who-forces` accept multiple roots analyzed in a bounded worker pool, reported sorted by root; `fix` skips clean repos entirely (no go invocations) — sweeps scale with drifted repos, not repo count                                                                                                                                                                                                                                                                    | `cmd/go-version-auto-configure/main.go` (`analyzeAll`, `applyAll`)                                                                           |
| JSON output                                | `--json` on check/fix/who-forces emits a stable camelCase machine contract versioned by a top-level `"schema": 2` field (per-repo findings, counts, applied/held-back/dep-forced/failures/discovery, floor matrix with `poisonerFloors`; schema 2 dropped the redundant `poisoners` strings) via `encoding/json/v2`                                                                                                                                                                    | `cmd/go-version-auto-configure/json.go`, `pkg/fix/who.go` (`ModuleFloors` tags)                                                              |
| Fleet-minor expectation gate               | `--expect-minor N` on check/fix: any go/toolchain directive or Nix/CI pin naming a higher minor fires `minor-exceeds-expectation` (suggest-only); minor-granularity comparison leaves accepted patch-form floors (x/text `1.26.0`, json/v2 `1.27.1`) silent; encodes the ADR-0001 fleet decision as a checkable policy                                                                                                                                                                 | `pkg/surface/rules.go` (`WithExpectedMinor`), `cmd/go-version-auto-configure/main.go` (`expectMinorOptions`)                                 |
| BuildFlow provider                         | Self-registering `toolsdk.Spec` via linter-autoconfigure-sdk's `ProviderFromSpec`; Detect + Repair; triggers on go/go.mod/go.work; honors BuildFlow dry-run context; HealthCheck verifies the go binary (context-aware)                                                                                                                                                                                                                                                                | `pkg/provider/provider.go` (`mustProvider`)                                                                                                  |
| CLI                                        | `check [--json] [--quiet] [--parallel N] [--expect-minor N] [root ...]` (exit 1 on drift), `fix [--dry-run] [--json] [--quiet] [--parallel N] [--expect-minor N] [root ...]`, `who-forces [--json] [--quiet] [--allow-partial] [--parallel N] [root ...]`, `version` (also `--version`)                                                                                                                                                                                                | `cmd/go-version-auto-configure/main.go` (`run`)                                                                                              |
| Test suite                                 | surface (parse/discover/analyze incl. toolchain + workspace-floor regressions), fix (edit verification, dep-forced naming, subdirectory modules, floor matrix), provider (registration, detect/repair/dry-run), CLI end-to-end incl.
